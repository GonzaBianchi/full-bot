# Discord Bot Multifunción con Panel de Control

Este proyecto contiene:
- Bot de Discord (Node.js + discord.js)
- Backend API (Node.js + Express)
- Panel de control web (Vite + React)

## Estructura

- `bot/` — Código del bot de Discord
- `backend/` — API backend y lógica de negocio
- `frontend/` — Panel de control web
